## 1. 新建「不良原因库」（若尚无）

字段：原因代码（文本）、原因名称（文本）、启用状态（单选）

初始样例：尺寸超差、外观不良、材质问题

## 2. 新建「不良明细表」

| 字段 | 类型 |
| --- | --- |
| 明细编号 | 自动编号 |
| 关联生产记录 | 关联→生产日志主表（单选） |
| 生产批号 | 查找引用←关联生产记录 |
| 完整追溯号 | 查找引用←关联生产记录（可选） |
| 不良数量 | 数字 |
| 不良原因 | 关联→不良原因库 |
| 状态 | 单选：待返工/已返工/已确认 |
| 返工后合格数 | 数字（P2可填） |
| 返工后报废数 | 数字 |

视图：品保·不良填报（可编辑）、班组长·待返工（筛选待返工）

## 3. 主表状态机（生产日志主表）

「工序下发状态」已有选项基础上，用自动化或公式辅助：

| 触发 | 状态 |
| --- | --- |
| 保存报工，无不良明细 | 可直接 **已确认**（无不良：有效数=合格数） |
| 有关联不良明细 | **待返工** |
| 返工数填完 | **待品保确认** |
| 品保确认 | **已确认** |

## 4. 有效数公式（有不良时）

```text
有效合格数量 = IF(是否有不良,
  IF(工序下发状态="已确认", 返工后合格数, BLANK()),
  合格数量)
有效报废数量 = IF(是否有不良,
  IF(工序下发状态="已确认", 返工后报废数, BLANK()),
  报废数量)
```

「是否有不良」= 关联不良明细计数>0（或复选框由自动化维护）

**无不良时保持 P0 规则：有效合格=合格数量，无需品保点确认。**

- 班组长·返工回填：状态=待返工
