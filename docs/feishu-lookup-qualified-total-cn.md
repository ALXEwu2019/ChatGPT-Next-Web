# 合格合计查找字段 — 手把手配置说明

> 表：**入库批次管控表**（`tbl6bCLJThyUaD8U`）  
> 目标：**批工序产量汇总表**（`tblu1h0huPW1Mixd`）  
> 汇总表已新增 **「生产区域」** 文本列（#4050 对账用）。

## 一、先理解匹配逻辑

| 管控表这一行 | 查找要匹配汇总表 |
| --- | --- |
| 批号文本 | 批号文本 |
| 产品 | 产品（关联同一产品记录） |
| 工序代码 | 工序代码（关联同一工序记录） |
| 生产区域（有值时，如 MG02） | 生产区域（MG02） |
| 生产区域（空，如 #2030） | 生产区域（A 或 B，见下文说明） |

## 二、配置「合格合计」查找字段（通用 3 条件）

### 步骤 1：打开字段设置

1. 打开飞书 → **机加工生产日志 v4**
2. 进入 **入库批次管控表**
3. 找到列头 **「合格合计」**
4. 点击列头右侧 **▼** 或 **右键** → **编辑字段** / **修改字段**

> 若还没有「合格合计」：点 **+** 新增字段 → 类型选 **查找引用**（或「查找」）。

### 步骤 2：选择关联表

| 设置项 | 填什么 |
| --- | --- |
| 关联的数据表 | **批工序产量汇总表** |
| 要引用的字段 | **合格合计** |

### 步骤 3：添加匹配条件（点「添加条件」）

**条件 1**

| 项 | 值 |
| --- | --- |
| 左侧 | **当前表** → `批号文本` |
| 运算符 | **等于** |
| 右侧 | **批工序产量汇总表** → `批号文本` |

**条件 2**

| 项 | 值 |
| --- | --- |
| 左侧 | **当前表** → `产品` |
| 运算符 | **等于** |
| 右侧 | **汇总表** → `产品` |

**条件 3**

| 项 | 值 |
| --- | --- |
| 左侧 | **当前表** → `工序代码` |
| 运算符 | **等于** |
| 右侧 | **汇总表** → `工序代码` |

### 步骤 4：保存

点 **确定** / **完成**。回到表格看「合格合计」是否出现数字。

## 三、#4050 带 MG02 / MG03 的行（加第 4 条条件）

止动块 #4050 管控表有两行同批 `S-260618-A`，分别 **MG02**、**MG03**。

在 **同一「合格合计」查找字段** 里再 **加一条条件**：

**条件 4**

| 项 | 值 |
| --- | --- |
| 左侧 | **当前表** → `生产区域` |
| 运算符 | **等于** |
| 右侧 | **汇总表** → `生产区域` |

这样：

- 管控行 `S-260618-A` + MG02 → 只匹配汇总里 `生产区域=MG02` 的那行  
- 管控行 `S-260618-A` + MG03 → 只匹配 `生产区域=MG03` 的那行  

**不必再人工对批工序键**，只要汇总表「生产区域」列有值（脚本会写入）。

## 四、#2030 行（生产区域为空）怎么对账

#2030 汇总按 **合并区 A / B** 拆行（不是 MG02），管控表行通常 **没有生产区域**。

两种做法（二选一）：

### 做法 A（推荐 P1）：管控表也加「合并区」列

1. 管控表增加单选 **合并区**：`A` / `B`（或文本）  
2. 查找加第 4 条件：`合并区` = 汇总表.`生产区域`  
3. STOPPER #2030 下发一行变两行（A 区、B 区各一行）——与汇总一致  

### 做法 B（简单）：#2030 暂用 3 条件 + 人工看汇总

- 3 条件只能匹配到 **一条** 汇总（飞书查找多匹配时行为可能不稳定）  
- **管理·批工序对账** 里 #2030 行先看「合格合计」是否有数；若不准，打开 **管理·汇总只读** 看 `S-xxx-#2030-A` / `-B` 两行合计  

当前测试批 `S-TEST-A` 在汇总表：

| 批工序键 | 合格合计 | 生产区域 |
| --- | --- | --- |
| S-TEST-A-#2030-A | 150 | A |
| S-TEST-A-#4050-MG02 | 80 | MG02 |
| S-TEST-A-#60 | 60 | （空） |

管控样例 `S-260617-A` #2030 若只有 3 条件、无区域，可能 **对不上** `S-TEST-A`（批号不同）；对 `S-260617-A` 报工并跑脚本后才会出数。

## 五、「对账差异」「是否超产」公式（若未配）

在 **入库批次管控表** 编辑公式字段：

**对账差异**

```text
合格合计 - 本工序下发数量
```

**是否超产**

```text
对账差异 > 0
```

（飞书公式里字段名用界面上的中文名点选，不要手打错字。）

## 六、配好后自检

| 检查 | 期望 |
| --- | --- |
| 管控 `S-260617-A` #2030 已下发 | 有报工且脚本跑过后，合格合计 > 0 |
| 管控 `S-260618-A` MG02 | 合格合计 = 对应 MG02 汇总行 |
| 对账差异 | 负数 = 未产够；正数 = 超产 |
| 汇总表 | 「管理·汇总只读」能看到 `生产区域` 列 |

定时脚本每天 8 / 12 / 20 点会更新汇总；改完查找后若仍为 0，点一次 **运行脚本** 或等下次 cron。
