# P2 公式修复手册 — 是否有不良 / 有效合格 / 有效报废

> **现象：** 飞书 AI 多轮修改后，测试专家报「验证不通过」；汇总脚本 0 行（有效合格为空）。  
> **根因：** 公式在「是否有不良」复选框 + `BLANK()` 组合下易报错；API 读不到 `有效合格数量` 即表示公式红叹号。

---

## 一、推荐策略：分两阶段

| 阶段 | 有效数公式 | 何时用 |
| --- | --- | --- |
| **P1 稳定期（当前）** | 无不良路径：有效合格=合格数量 | 先保证汇总、对账、选批 |
| **P2 启用不良后** | 再打开有不良分支 | 不良明细表有数据后 |

**我已通过 API 将公式恢复为 P0 简化版**（有效合格=合格数量），汇总应可恢复。你在飞书界面确认无红叹号即可。

## 二、P1 稳定公式（手工粘贴到飞书公式编辑器）

在 **生产日志主表** → 编辑字段 → 用界面 **点选字段**，不要手打内部 ID。

### 有效合格数量

```text
合格数量
```

（P1 无不良：与 §12 C1 一致。）

### 有效报废数量

```text
IF(ISBLANK(报废数量), 0, 报废数量)
```

### 是否有不良

- 类型：**复选框**
- P1 可全部 **不勾选**；P2 再改为公式或自动化（见第四节）

## 三、P2 完整公式（不良表有数据后再换）

**前提：** 不良明细表已建；主表有「返工后合格数」「返工后报废数」数字字段。

### 有效合格数量

```text
IF(
  是否有不良,
  IF(
    工序下发状态 = "已确认",
    返工后合格数,
    BLANK()
  ),
  合格数量
)
```

### 有效报废数量

```text
IF(
  是否有不良,
  IF(
    工序下发状态 = "已确认",
    返工后报废数,
    BLANK()
  ),
  IF(ISBLANK(报废数量), 0, 报废数量)
)
```

### 常见报错原因

| 错误写法 | 正确做法 |
| --- | --- |
| 在 IF 里直接写复选框名不加判断 | 用 `是否有不良` 作 IF 第一参数（飞书视其为 true/false） |
| 非已确认返回 0 | 应返回 **BLANK()**，否则未确认也进汇总 |
| 有不良但返工数为空 | 状态改「待返工」前保持未确认；确认前应为 BLANK |
| 有效合格引用自己 | 禁止循环引用 |

## 四、是否有不良 — 三种实现（由易到难）

### 方案 A（P1）：手动复选框

- 无不良：**不勾选**
- 有不良：勾选 → 走返工流程  
- 适合先跑通产线

### 方案 B（P2 推荐）：查找引用计数

新增公式字段 **不良明细条数**（若平台支持）或用手动维护复选框 + 自动化：

- 触发：不良明细新增关联本行  
- 动作：勾选主表「是否有不良」

### 方案 C：公式字段（只读）

若主表能 **关联** 不良明细（双向），用：

```text
COUNT(关联不良明细) > 0
```

（字段名以你表为准；飞书部分版本不支持 COUNT 关联，则用方案 B。）

## 五、状态机（与公式配合）

| 是否有不良 | 工序下发状态 | 有效合格应显示 |
| --- | --- | --- |
| 否 | 已确认 | = 合格数量 |
| 否 | 已报工 | = 合格数量（P1）或 BLANK（严格 P2） |
| 是 | 待返工/待品保 | BLANK |
| 是 | 已确认 | = 返工后合格数 |
