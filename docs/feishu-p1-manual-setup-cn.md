## 一、上道批号 · 各视图关联筛选（6 个视图）

### 通用操作路径

1. 打开 **机加工生产日志 v4** → **生产日志主表**
2. 顶部切换到 **对应报工视图**（见下表）
3. 点击列头 **「上道批号」**（若视图里是「上道批号_STOPPER#4050」等专用字段，则点那个字段）
4. **编辑字段** / 字段设置 → **关联记录筛选**（或「筛选关联记录」）
5. 选择 **满足所有条件**
6. 逐条添加下表条件 → **保存**
7. **不要**添加「生产区域」相关条件

### 筛选条件表

| 视图名称 | 条件 1 | 条件 2 | 条件 3 |
| --- | --- | --- | --- |
| STOPPER·#4050 报工 | 工序下发状态 **等于** 已确认 | 有效合格数量 **大于** 0 | 工序代码 **等于** #2030（选工序表那条记录） |
| STOPPER·#60 报工 | 同上 | 同上 | 工序代码 **等于** #4050 |
| STOPPER·#70 报工 | 同上 | 同上 | 工序代码 **等于** #60 |
| 止动块·#60 报工 | 同上 | 同上 | 工序代码 **等于** #4050 |
| 止动块·#70 报工 | 同上 | 同上 | 工序代码 **等于** #60 |
| 止动块·#80 报工 | 同上 | 同上 | 工序代码 **等于** #70 |

### 界面点选技巧

- **工序代码**：在筛选里选「关联记录」→ 工序表 → 点选 `#2030` / `#4050` 等（显示可能是「#2030」或工序名称）
- 若无法按关联筛选用 **工序代码文本** 等于 `#2030`（主表公式字段，部分版本支持）
- 每个视图 **单独配置**，互不影响

### 批号带出（下道）

配置完筛选后，确认该视图 **生产批号** 为公式/只读，来源：

```text
生产批号 = 上道批号.批号文本
```

或使用已有字段 **生产批号_上道** 显示。

## 三、生产批号只读（各报工视图）

对每个 **报工视图**（#2030 / #4050 / #60 …）：

1. 进入该视图  
2. 点击 **生产批号** 列头 → **编辑字段** 或 **字段权限**  
3. 关闭「可手动编辑」/ 设为 **只读**（仅公式或查找带出）  
4. 若界面无只读选项：在 **视图** 设置里隐藏该字段的编辑，或依赖公式字段（用户改不了公式）

## 四、合格合计查找（管控表对账）

### 方案 A：通用「合格合计」（推荐，所有工序）

**入库批次管控表** → **合格合计** → 编辑字段：

| 设置 | 值 |
| --- | --- |
| 类型 | 查找引用 |
| 关联表 | 批工序产量汇总表 |
| 引用字段 | 合格合计 |
| 条件关系 | **所有** |

| # | 条件 |
| --- | --- |
| 1 | 批号文本 **等于** 汇总.批号文本 |
| 2 | 产品 **等于** 汇总.产品 |
| 3 | 工序代码 **等于** 汇总.工序代码 |
| 4 | 生产区域 **等于** 汇总.生产区域 |

- #4050 行 MG02/MG03：**靠条件 4 自动区分**，无需对批工序键  
- #2030 行无生产区域：两侧都为空时匹配；若汇总按 A/B 分行，管控也需有对应「生产区域」或「合并区」列（P1 可暂人工看汇总）

### 方案 B：你已配置的「合格合计_#4050」

若已按截图配好 4 条件查找，**#4050 + MG02/MG03 行用该字段即可**，无需 IF 公式。

**对账差异**（公式）示例：

```text
IF(
  AND(CONTAINS(工序代码,"#4050"), OR(生产区域="MG02", 生产区域="MG03")),
  合格合计_#4050 - 本工序下发数量,
  合格合计 - 本工序下发数量
)
```

（用界面点选字段；若无 `合格合计_#4050` 则统一用 `合格合计`。）

### 是否超产

```text
对账差异 > 0
```

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 上道批号下拉为空 | 上道是否 **已确认** 且 **有效合格>0**；工序筛选是否选对 |
| 合格合计为 0 | 批号是否与汇总一致；是否跑过 `sync_batch_summary.py` |
| 多个「上道批号_xxx」字段 | 每个视图用各自专用字段配置同一套筛选规则 |
| 生产批号为空 | 首道需选管控批；下道需选上道批号 |
