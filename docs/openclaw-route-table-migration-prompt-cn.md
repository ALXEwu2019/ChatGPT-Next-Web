请在「机加工生产日志 v4」中，把 **产品工序对照表** 的路线数据，写入 **产品工序路线表**（不要新建重复表；若仅有对照表，可改名为路线表或在对照表上补字段）。

## 规则（必须遵守 v4）

1. **工序代码** 只关联 **工序表** 中的通用代码：`#2030`、`#4050`、`#60`、`#70`、`#80`、`#1020`、`#3040`、`#50` 等，**不要**用带 `-STOPPER`、`-止动块`、`-PTJ92` 后缀的工序名写入路线表。
2. **产品** 关联 **产品表**：`STOPPER`、`止动块`（或代码 `ZHIDONG`）、`PTJ92`。
3. 一条路线行 = 一个产品 + 一个工序 + 顺序 + 是否首道 + 上道工序 + 汇总维度 + 批号来源。
4. **不要**修改生产日志主表、汇总脚本规则。

## 操作步骤

1. 打开 **产品工序路线表**（或在对照表上增加缺失列：是否首道、上道工序、汇总维度、批号来源）。
2. **清空**路线表中与上述 11 行冲突的旧测试数据（保留表结构）。
3. 按上表 **录入或批量导入 11 行**，工序代码、产品必须用 **关联字段** 选记录，不要手打文本。
4. 对照表可保留作只读参考，或标记「已迁移至路线表」。

## 完成后回报

1. 产品工序路线表共 **11 行**
2. STOPPER 首道是否为 #2030、止动块首道是否为 #4050
3. 任意一行「工序代码」关联是否指向工序表（非对照表文本）
4. 截图或列出 11 行「顺序 + 产品 + 工序代码」

**禁止：** 重建应用、删生产日志主表、改汇总表自动化。
