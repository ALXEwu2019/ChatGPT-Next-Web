### 3.2 有效数公式（P0 简化版）

P0 无不良表时，全部按「无不良」路径：

```text
有效合格数量 = 合格数量
有效报废数量 = 报废数量
```

P2 启用不良闭环后改为：

```text
有效合格数量 = IF(是否有不良,
  IF(工序下发状态="已确认", 返工后合格数, BLANK()),
  合格数量)
有效报废数量 = IF(是否有不良,
  IF(工序下发状态="已确认", 返工后报废数, BLANK()),
  报废数量)
```

**已定稿：** 无不良时自动有效数=合格数，**无需品保点确认**。

### 3.3 工序下发状态

| 选项 | P0 用途 |
| --- | --- |
| 待报工 | 草稿 |
| 已报工 | 已提交产量 |
| 待返工 | P2 |
| 待品保确认 | P2 |
| 已确认 | **计入汇总、可进上道批号池** |

P0 测试数据直接将状态设为 `已确认` 即可触发汇总脚本。

### 3.4 完整追溯号公式

```text
完整追溯号 = IF(需要追溯号,
  批号文本 & "-" & 填报月日 & "-" & 末段值,
  BLANK())
```

- `需要追溯号`：自产品追溯规则表查找（产品+工序）
- `末段值`：若段3来源=生产区域 → `生产区域`；若=工位代码 → `工位代码`
- #70、#80：`需要追溯号=false`，公式结果为空白

### 3.5 生产区域单选选项

**#2030 视图：**

```
A1, A2, B1, B2
```

**#4050 视图：**

```
MG02, MG03, MG04
```
