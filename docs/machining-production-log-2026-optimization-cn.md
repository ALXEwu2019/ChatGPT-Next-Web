## 6. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 删除字段导致旧视图报错 | 先隐藏 1 周，视图改字段后再删 |
| 工序去重破坏历史关联 | 路线表先改关联，主表历史行保留原 record 映射表 |
| 管控表字段改名影响仓库表 | 仓库出入库表关联暂不动，新增 v4 字段并行 |
| 汇总脚本字段名不一致 | 用 `config.2026.json` 的 `field_mapping` 显式映射 |

**回滚：** 使用阶段 A 备份 Base；脚本仅写汇总表，不写主表历史。
