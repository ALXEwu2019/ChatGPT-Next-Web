# 机加工车间生产日志管理方案

## 目标

面向机加工车间的班组长、调度、工艺和质检人员，使用飞书 AI 辅助完成生产日志的收集、整理、追踪和复盘。系统以“班次日志”为核心，把零散口述或文字记录转换为可沉淀的数据表、异常闭环和日报周报。

## 核心场景

1. **班次日志录入**：记录日期、班次、机台、工单、零件、工序、计划数量、完成数量、合格数量、不良数量、停机时间和交接事项。
2. **异常跟踪**：记录设备、刀具、质量、物料、工艺、人员、安全等异常，并明确责任人、处理措施、截止时间和状态。
3. **产能复盘**：对比计划与实际，计算达成率、良率、停机影响和主要损失原因。
4. **交接班管理**：输出下一班必须关注的工单、设备、质量风险、待检件和未关闭问题。
5. **管理报表**：按日、周、月汇总产量、良率、停机、异常数量和改善建议。

## 飞书多维表格建议

### 生产日志表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 日期 | 日期 | 生产日期 |
| 班次 | 单选 | 白班、夜班、中班 |
| 班组/负责人 | 人员 | 当班负责人 |
| 机台编号 | 文本/单选 | 如 CNC-01、车床-02 |
| 工单号 | 文本 | 生产工单或任务单编号 |
| 零件名称/图号 | 文本 | 加工对象 |
| 工序 | 文本/单选 | 车、铣、钻、磨、检验等 |
| 计划数量 | 数字 | 当班计划 |
| 完成数量 | 数字 | 当班产出 |
| 合格数量 | 数字 | 合格产出 |
| 不良数量 | 数字 | 不良产出 |
| 达成率 | 公式 | 完成数量 / 计划数量 |
| 良率 | 公式 | 合格数量 / 完成数量 |
| 停机分钟 | 数字 | 当班累计停机 |
| 停机原因 | 多选 | 设备、刀具、物料、质量、调机、待检、其他 |
| 备注 | 长文本 | 现场补充信息 |

### 异常闭环表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 异常编号 | 自动编号 | 问题唯一标识 |
| 关联日期/班次 | 关联 | 关联生产日志 |
| 异常类型 | 单选 | 设备、刀具、质量、物料、工艺、安全、人员、其他 |
| 问题描述 | 长文本 | 发生了什么、影响范围 |
| 影响数量/时间 | 数字/文本 | 报废、返工、停机等影响 |
| 临时措施 | 长文本 | 当班处理动作 |
| 根因判断 | 长文本 | 初步原因或 5Why 结果 |
| 责任人 | 人员 | 跟进负责人 |
| 截止时间 | 日期 | 关闭节点 |
| 状态 | 单选 | 新建、处理中、待验证、已关闭 |
| 验证结果 | 长文本 | 关闭依据 |

## 飞书 AI 使用方式

1. 现场人员用自然语言描述当班情况，例如：“白班 CNC-03 加工 A123 支架，计划 120 件，完成 110 件，合格 106 件，刀具崩刃停机 35 分钟，4 件尺寸超差，夜班注意换刀后首件检验。”
2. 使用“机加工生产日志助手”面具，让 AI 输出标准化 Markdown 表格、异常闭环、交接事项和日报。
3. 将表格复制到飞书文档或多维表格；稳定后可通过飞书自动化把 AI 输出字段写入数据表。
4. 管理人员每天基于数据表视图查看未关闭异常、低达成率工单、低良率机台和停机 Top 原因。

## 推荐输出格式

AI 每次处理班次记录时，应固定输出以下内容：

1. **缺失信息检查**：列出影响记录完整性的缺失字段。
2. **生产日志表**：一行或多行结构化记录。
3. **异常闭环表**：只有存在异常时输出，包含负责人和下一步动作。
4. **交接班清单**：下一班必须关注的事项。
5. **日报摘要**：用 3 到 5 条概括产量、质量、停机和风险。
6. **改进建议**：只提出可执行、可验证的短期动作。

## 当前已完成

- 明确了生产日志和异常闭环的字段结构。
- 增加了可在应用内直接使用的“机加工生产日志助手”内置面具。
- 面具输出格式已对齐飞书文档和多维表格复制粘贴场景。

## 后续可继续扩展

- 增加企业专属字段，例如客户、项目、工艺版本、检具编号、报废原因代码。
- 增加周报/月报面具，用于跨班次汇总分析。
- 对接飞书开放平台，将结构化结果自动写入多维表格。
- 增加异常提醒规则，例如停机超过 30 分钟、良率低于 98%、异常超过截止时间未关闭。
