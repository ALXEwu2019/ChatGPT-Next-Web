## 三、四个视图如何设置

### 1. 启用·按产品工序（110 行）

**用途：** 品保/班组长查看当前在用的全部规则，按产品、工序分组浏览。

**设置步骤：**

1. 复制「默认·全部规则」视图 → 重命名为 `启用·按产品工序`
2. **筛选条件**（1 条）  
   - 字段：`启用状态`  
   - 条件：等于  
   - 值：`启用`
3. **分组**（两级）  
   - 第一级：`关联产品`  
   - 第二级：`工序代码`
4. **排序**（可选）  
   - `工序代码` 升序 → `不良原因` 升序
5. **显示列**（建议）  
   规则编号、规则名称、关联产品、工序代码、不良原因、不良类型、启用状态

---

### 2. 返工原因（23 行）

**用途：** 填报不良明细时，先选「返工」再从此视图选原因（或作对照清单）。

**设置步骤：**

1. 新建视图 → 重命名 `返工原因`
2. **筛选条件**（2 条，且关系为 **且**）  

   | 字段 | 条件 | 值 |
   | --- | --- | --- |
   | 启用状态 | 等于 | 启用 |
   | 不良类型 | 等于 | 返工 |

3. **分组**（可选）：`关联产品` → `工序代码`
4. **显示列**：规则名称、关联产品、工序代码、不良原因、不良类型

---

### 3. 报废原因（87 行）

**用途：** 填报不良明细时，选「报废」后的原因清单。

**设置步骤：**

1. 新建视图 → 重命名 `报废原因`
2. **筛选条件**（2 条，且）  

   | 字段 | 条件 | 值 |
   | --- | --- | --- |
   | 启用状态 | 等于 | 启用 |
   | 不良类型 | 等于 | 报废 |

3. **分组**（可选）：`关联产品` → `工序代码`
4. **显示列**：同返工原因视图

---

### 4. 历史·止动块#2030（27 行）

**用途：** v4 止动块首道为 #4050，不走 #2030；此视图保留旧规则备查，**全部停用**。

**设置步骤：**

1. 新建视图 → 重命名 `历史·止动块#2030`
2. **筛选条件**（2 条，且）  

   | 字段 | 条件 | 值 |
   | --- | --- | --- |
   | 关联产品 | 等于 | 止动块（或 ZHIDONG） |
   | 工序代码 | 等于 | #2030 |

3. **分组**（可选）：`不良类型`（返工/报废）
4. **显示列**：规则名称、不良原因、不良类型、启用状态（应全为 **停用**）

> 报工视图 **不要** 引用此视图；仅档案查阅。

## 四、如何「添加内容」（新增一条规则）

在 **启用·按产品工序** 或任意视图点 **+ 新建记录**，填写：

| 字段 | 填法 |
| --- | --- |
| 关联产品 | 从下拉选产品（必须关联，勿手打） |
| 工序代码 | 从下拉选 `#2030` 等通用代码 |
| 不良原因 | 从不良原因库选（若无先去原因库补） |
| 不良类型 | 返工 或 报废 |
| 启用状态 | 新规则填 **启用**；历史链填 **停用** |
| 规则名称 | 可手填 `产品-工序-原因-返工/报废`，或留空后批量补 |

**注意：** 同一「产品 + 工序 + 不良原因」可同时有 **返工** 和 **报废** 两行，属正常。

### 示例：给 STOPPER·#60 增加返工原因「磕碰」

1. 确认不良原因库有「磕碰」
2. 在「返工原因」视图 → 新建  
   - 关联产品：STOPPER  
   - 工序代码：#60  
   - 不良原因：磕碰  
   - 不良类型：返工  
   - 启用状态：启用  
3. 保存后该条自动出现在「启用·按产品工序」和「返工原因」视图

## 六、与不良明细表联动（P2）

不良明细填报建议流程：

1. 从生产记录带出 **产品 + 工序代码**
2. 操作工/品保先选 **返工** 或 **报废**
3. 不良原因下拉范围 = 联动规则表中  
   `产品 + 工序 + 不良类型 + 启用状态=启用` 匹配的行

若飞书暂不支持关联字段动态筛选，可：
- 品保用「返工原因」「报废原因」视图人工对照选择；或
- 按产品+工序拆分子视图（如 `STOPPER·#2030·返工`）

## 七、常见问题

| 问题 | 处理 |
| --- | --- |
| 视图显示 0 行 | 检查筛选是否仍用旧字段「默认处置类型」，应改为 **不良类型** |
| 返工+报废同一原因看不到 | 两条规则需分别建，不良类型不同 |
| 止动块 #2030 出现在报工 | 将该批规则 **启用状态=停用**，仅保留在历史视图 |
| 批量补 137 行 | 运行 `feishu-batch-summary-sync/import_defect_linkage.py` |
