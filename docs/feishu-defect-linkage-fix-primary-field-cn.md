## 一、为什么「不良类型」锁死？

飞书多维表格 **第一列 = 索引列（主字段）**，有以下限制：

| 限制 | 说明 |
| --- | --- |
| 不能删除 | API 报错 `The Primary Field cannot be deleted` |
| 不能隐藏 | 字段配置里无「隐藏」 |
| 不能改类型为关联 | 主字段仅支持：文本、数字、单选、公式、自动编号等 |

当前问题：

1. 飞书 AI 把 **「不良类型」设成了主字段**（单选：返工/报废）。
2. 真正写入数据的是 **「默认处置类型」**，主字段 **不良类型一直为空** → 列表里每行标题空白，像「没内容」。
3. **不良类型** 与 **默认处置类型** 语义重复，属于建表错误。

**已通过 API 把「默认处置类型」同步回填到「不良类型」137 行**，刷新后应能看到返工/报废。

## 二、推荐根治方案（换主字段 → 删重复列）

### 手工步骤（约 2 分钟）

1. 打开 **不良原因联动规则表** → **字段配置**（表头右侧 + 或 ⋮）。
2. 找到 **规则编号**（自动编号，已存在）→ **设为索引列 / 设为主字段**。
3. 确认第一列变为 **1、2、3…** 的规则编号后：
   - **删除** 列「不良类型」（此时已非主字段，可删）。
   - **只保留**「默认处置类型」表示返工/报废。
4. 清理「默认处置类型」脏选项（若还有）：
   - 只保留：**返工**、**报废**
   - 删除：`#2030车床自动化-STOPPER` 等工序名选项。
5. 清理「启用状态」脏选项：
   - 只保留：**启用**、**停用**
   - 删除：`#2030`、`#1020` 等工序代码选项。
6. 重建视图筛选（绑定 **默认处置类型**、**启用状态**，不要用已删的「不良类型」）。
